# donkey-app
Elk web version

Accessible from https://sudarpo.net/donkey-app

To use your own exchange rate, check **Use custom rate** below the conversion list and enter the amount in the direction shown beside the input (normally the API's stronger-to-weaker direction). The rate is saved for that currency pair, including when you swap its direction, and stays active after a reload or API update. Uncheck the box to use the API rate without discarding your saved value. Entering a custom rate for another pair replaces the previously saved pair.
